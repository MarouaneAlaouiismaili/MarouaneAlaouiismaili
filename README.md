## 🚀 Featured work

### CVBN — Personal AI CLI Agent

**CVBN** is my main software project: a local-first, Claude-Code-like AI command-line environment designed to make LLMs useful inside real development workflows.

The project explores:

- 🧠 Multiple AI providers, including local and hosted models
- 💻 Command-line workflows for practical software development
- 🛠️ Tool-driven execution, sessions, permissions, and extensibility
- 🔌 MCP-oriented integrations and external tool workflows
- 🔐 Controlled execution and permission-aware automation
- 🐞 **Bug Bounty Professionnel** — an experimental security-investigation workflow that can generate focused Python investigation programs from previous evidence, while respecting scope and execution controls

**Project status:** actively evolving. Features and interfaces may change as development continues.

> I prefer documenting capabilities and limitations accurately rather than presenting experimental features as production-ready.
